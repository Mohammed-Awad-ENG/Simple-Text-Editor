## ✨ Features — Everything PDF Editors Should've Had

<table>
<tr>
<td>

### Rich Text Editing
- **Bold**, *Italic*, <ins>Underline</ins>, ~~Strikethrough~~
- Headings (H1 → H6)
- Text alignment (Left, Center, Right, Justify)
- Custom line height control

</td>
<td>

### 🎭 Full Style Control
- 🖌️ Text color picker
- 🎨 Background/highlight colors
- 🔤 Font family selector *(fonts that actually work)*
- 📐 Custom font sizes

</td>
</tr>
<tr>
<td>

### 📊 Tables That Don't Break
- Insert & manage tables
- Add/remove rows & columns
- Merge & split cells
- Cell-level styling (borders, padding, colors)
- Right-click context menu

</td>
<td>

### 📦 Everything Else
- 🖼️ Image insertion & resizing
- 🔗 Clickable links
- ✅ Task lists / checklists
- 📝 Bullet & numbered lists
- 💬 Blockquotes & code blocks
- 📄 **Export to PDF** *(the irony is not lost on me)*

</td>
</tr>
</table>

## Getting Started

```bash
# Clone this rage-fueled project
git clone https://github.com/Mohammed-Awad-ENG/Simple-Text-Editor.git

# Enter the promised land
cd Simple-Text-Editor

# Install dependencies (they're all FREE btw)
npm install

# Launch the editor
npm run dev
```

Then open your browser and go to `http://localhost:5173` 🎉
